01. Overview

Timio is a real-time experiment where I designed and built a tiny time-tracking app with AI as an active partner. No clients, no long roadmap—just curiosity: what happens when I let AI into my everyday workflow?

The trigger was simple: someone close to me disliked Excel but needed to log hours and earnings. I kept it realistic—two days, free AI tools, and a lightweight app that mirrors how I actually work as a mom and freelancer.

48-hour MVP from idea to demo
Automated hour logging & exports
Showcases AI-first workflow

What is Timio?

A lightweight time-tracking web app built as a personal MVP experiment to see how AI can support real product design and front-end workflows.

Purpose

Explore a hybrid workflow where product design, code, and AI coexist in real time. This is a learning experiment, not a production-ready app.

⸻

02. User & Journey

The user spark was someone who dislikes Excel and needs a zero-friction way to track hours and earnings on mobile. I framed Timio as “minimum friction for a non-tech user,” with plain language and one-screen actions.

  1. User opens the app
  2. Adds a new work entry (client, date, hours, rate, description)
  3. Sees totals per entry
  4. Repeats for more clients
  5. Exports to CSV/Excel or PDF
  6. Optionally uploads a file to import records

⸻

03. Thinking in the Solution

I kept the MVP intentionally small to validate the experience, not to ship a full product. Must-haves:

  • Log hours worked
  • Assign hours to a client
  • Set hourly rate per client
  • View totals per entry
  • Export records to PDF or Excel
  • Upload an existing file to add entries

Explicitly out-of-scope to avoid scope creep:

  • User accounts or login
  • Persistent multi-account storage or advanced dashboards
  • Gamification
  • Cloud integrations (e.g., Google Drive)
  • Advanced client history

Identity and interface choices:

  • Name: Timio — short, friendly, easy to remember
  • Visual style: Notion-inspired, calm, human
  • Blocks: responsive layout, simple inputs, table-based entries with automatic totals, export/import actions

⸻

04. Vibe Coding (Prompt to Interface)

I rotated through VS Code + ChatGPT plugin, GitHub Copilot / Compiler, and Cursor to feel AI up close. The goal wasn’t to crown a winner but to sense how each shaped focus, prompts, and iteration speed. I stayed with mostly free AI resources and kept time honest—two days, no all-nighters.

Main prompt I used with ChatGPT:

Act as a front-end assistant.

Create a minimal, responsive HTML layout for a web app called "Timio", a time-tracking tool.

Requirements:
- Use semantic HTML.
- Add a header with the logo "Timio" and a short subtitle.
- Add a hero section with a title, short description and space for an illustration.
- Below that, add a section called "My hours" with:
  - A button to add a new entry.
  - A button to upload a file.
  - A responsive table with columns: Client, Description, Date, Hours, Rate, Total, Actions.
Use class names that I can later style with Bootstrap and custom CSS.
Language: Spanish labels in the UI.

⸻

05. Final Product

Timio is more than a tiny app. It is:

  • My first intentional end-to-end AI-assisted product
  • A hands-on exercise in true MVP thinking
  • A way to work with free AI tools in a real freelance context
  • A reminder that design also happens inside the code editor
  • A blend of UX, product thinking, front-end, AI, and real-life constraints

If Timio evolved into a full product, the roadmap would include: user accounts and secure storage, smart client/project management, income and goal tracking, gentle gamification, cloud sync, and AI-powered productivity insights.

Final reflection: Timio is my first real “vibe coding” project—where intuition, design, code, and AI coexist in real time. It’s not about perfection. It’s about learning in public and adapting to the future of product design.
